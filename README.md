# BookSpace – ระบบจองโต๊ะและพื้นที่ส่วนกลาง

เว็บจองโต๊ะ (HTML + CSS + JavaScript) ใช้ LocalStorage จำลองฐานข้อมูลและระบบ Login

## โครงสร้างไฟล์
```
index.html     โครงหน้าเว็บ (โหลด Chart.js ผ่าน CDN)
css/style.css  สไตล์ ธีมส้ม-ขาว โหมดมืด/สว่าง และ Responsive
js/app.js      ตรรกะทั้งหมด: Login, จองโต๊ะ, เช็กอิน, Dashboard, หน้า Admin
```

## ฟีเจอร์
- สมัครสมาชิก / เข้าสู่ระบบ แยกบทบาท User และ Admin
- ค้นหาโต๊ะว่างตามวัน เวลา และประเภทพื้นที่ พร้อมแผนผังโต๊ะ 12 ตัวแบบคลิกจอง
- ตรวจเวลาทับซ้อน จำกัดชั่วโมงจองต่อวัน เช็กอิน และยกเลิกสิทธิ์อัตโนมัติเมื่อไม่มาแสดงตัว
- Dashboard (Chart.js) และหน้าจัดการโต๊ะ นโยบาย และคิวสำหรับ Admin
- โหมดมืด/สว่าง และรองรับมือถือ (≤576px) แท็บเล็ต (≤992px) เดสก์ท็อป

## หมายเหตุ
